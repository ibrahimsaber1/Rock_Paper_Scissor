# Rock Paper Scissors Game 🎮

A simple command-line Rock Paper Scissors game written in Python.

## About
This was my first Python project during my data science learning journey at Epsilon AI. A classic game implementation to get familiar with Python basics.

## How to Play
1. Run the script: `python game.py`
2. Enter your choice: 'rock', 'paper', or 'scissors'
3. Play 3 rounds against the computer
4. See who wins the best of 3!
5. Choose to play again or quit

## Features
- Best of 3 rounds
- Score tracking
- Input validation
- ASCII art for game results
- Replay option

## Requirements
- Python 3.x

## Usage
```bash
python game.py
```
